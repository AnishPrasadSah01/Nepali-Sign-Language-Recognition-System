# Error Analysis

## Common Misclassifications
1. KA ↔ KHA (visually similar)
2. MA ↔ M_SHA (hand position)

## Root Causes
- Lighting conditions
- Hand orientation variations
- Limited edge cases in training

## Recommendations
1. Increase training data for KA and KHA
2. Add varied lighting conditions to dataset
3. Implement data augmentation for rotations
